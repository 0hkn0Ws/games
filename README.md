# АКАДЕМИЯ ХИМИЧЕСКИХ ТАЙН — детективная игра по школьной химии

Оригинальная 3D-игра: вы поступаете в академию исследователей и раскрываете тайны,
применяя школьную химию. Дружелюбная мультяшная графика, выразительные персонажи,
плавный тёплый свет.

**Играть:** откройте `chem-academy.html` в браузере (нужен `three.min.js` и `chem-data.js` рядом).

> Это **рабочий вертикальный срез** (Этап 1): одна полная учебная миссия, все
> основные системы и Архив элементов. Остальные главы курса — заготовки, они честно
> помечены как «в разработке».

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | ходить |
| `Мышь` | обзор камеры |
| `E` | осмотреть объект / поговорить |
| `J` | журнал расследования |
| `T` | Архив элементов |
| `Esc` | пауза |

На телефоне — экранный джойстик и кнопки.

## Что реализовано

### Игровой цикл (как в ТЗ)
1. **Получить дело** — наставник объясняет, что пропал образец.
2. **Осмотреть место** — вы ходите по лаборатории в 3D и находите 5 улик.
3. **Собрать данные** — улики записываются в журнал.
4. **Учебные задания** — 6 заданий разных типов.
5. **Сделать вывод** — версия, подтверждённая уликами.
6. **Обратная связь** — разбор правильного ответа и типичных ошибок.
7. **Зафиксировать знания** — термины, элементы и навыки в журнале.
8. **Открыть следующий этап** — экран итога миссии.

### Глава 1: «Пропавший образец»
Темы: вещества и тела, физические свойства, объект и материал, правила лаборатории.

**Шесть типов заданий** (не только «выбор из трёх»):

| Тип | Задание |
|---|---|
| Наблюдение | отделить наблюдение от вывода |
| Классификация | распределить: тело или вещество |
| Сопоставление | вещество ↔ физическое свойство |
| Сбор доказательств | какие улики подтверждают версию |
| Правила лаборатории | что разрешено, а что опасно |
| Вывод | версия, объясняющая все улики |

### Архив элементов
- упрощённая периодическая таблица (20 элементов, школьный уровень);
- карточка элемента: символ, название, номер, группа, факт;
- изученные элементы помечены зелёной рамкой;
- **тренировка**: символ ↔ название в обе стороны;
- список изученного.

### Подсказки и обратная связь
- три уровня подсказок, выдаются постепенно;
- при ошибке — объяснение, **что именно** не сходится с уликами;
- ошибка **не блокирует** прогресс и не отнимает достижения;
- после двух ошибок подсказка появляется сама.

### Доступность
Раздельные громкости музыки и звуков, размер текста, режим «меньше анимаций»,
повышенная контрастность, субтитры реплик, **таймеров нет вообще**.

### Сохранение
Прогресс (улики, задания, термины, элементы, навыки) хранится в браузере.
Повреждённое сохранение не роняет игру — она просто начнётся заново.

## Архитектура

Содержание **отделено от кода**:

| Файл | Что внутри |
|---|---|
| `chem-academy.html` | движок: 3D, персонажи, интерфейс, логика |
| `chem-data.js` | **все учебные данные**: главы, задания, элементы, реплики, улики |

Чтобы поменять порядок глав, добавить задание или элемент — правится только
`chem-data.js`. Записи заданий содержат: id, главу, учебную цель, условие,
варианты, верный ответ, разбор, типичные ошибки, уровни подсказок.

## Химическая корректность

Проверено автотестами: названия и символы элементов, однозначность верных ответов,
наличие разбора для каждого неверного варианта. Упрощённые модели (например,
таблица из 20 элементов) обозначены как учебные.

## Безопасность

Все опыты в игре — **учебные и смоделированные**. Игра прямо напоминает, что
настоящие опыты выполняют только в лаборатории по правилам и под руководством
учителя. Опасных инструкций и рецептов нет.

# АРЕНА — 3D шутер от первого лица


Волны монстров на неоновой арене. Из убитых выпадают **патроны**, **новое оружие**
и аптечки — подбираются, если просто подойти.

**Играть:** откройте `shooter-3d.html` в браузере (нужен `three.min.js` рядом).

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение |
| `Мышь` | обзор |
| `ЛКМ` | огонь (автоматический для авто-оружия) |
| `R` | перезарядка |
| `1`…`6` | выбор оружия |
| `Q` | следующее оружие |
| `Shift` | бег |
| `Esc` | пауза |

## Оружие (6 стволов, выпадают из монстров)

| Оружие | Особенность |
|---|---|
| **Пистолет** | стартовый, точный, магазин 12 |
| **ПП** | скорострельный, но сильно косит |
| **Дробовик** | 9 дробинок, в упор сносит всё |
| **Винтовка** | пробивает 3 врагов насквозь, в голову — тройной урон |
| **Плазмер** | взрыв при попадании, задевает всех рядом |
| **Миниган** | море свинца, магазин 150, долгая перезарядка |

У **каждого ствола свой магазин и свой запас патронов** — переключение мгновенное.
Найденное оружие приходит заряженным. Патроны из ящиков идут в запас того оружия,
что сейчас в руках. Список найденного — внизу экрана, активное подсвечено.

## Лут из монстров

| Предмет | Как выглядит | Шанс |
|---|---|---|
| **Патроны** | жёлтый ящик с лентой | 42% (у крупных больше) |
| **Оружие** | ствол с кольцом-ореолом | 13% (у крупных ×2.2) |
| **Аптечка** | зелёная с крестом | 14% |

Оружие выпадает только то, **которого у вас ещё нет** — и предпочтительно помощнее
текущего. Если всё оружие собрано, вместо него выпадут патроны.

## Враги

**Гоблин** (быстрый, слабый), **Громила** (крепкий, крупный) и **Босс-бугай**
(очень живучий, даёт больше лута). Каждая 4-я волна — босс.

## Как играть

- Убивайте монстров и **подбирайте лут** — это основа прогресса.
- Следите за патронами: если магазин пуст, а запаса нет, оружие бесполезно.
- **В голову** — 2.5× урона (у винтовки 3.4×).
- Между волнами даётся передышка и немного здоровья.

# БОЙ НА ПОДУШКАХ — 2D файтинг, два кота

Вид сбоку, плавная (не пиксельная) графика. Рыжий кот **Мурзик** идёт по лестнице
из **6 противников** и сражается подушками. У каждого врага свой характер.

**Играть:** откройте `cats-pillow.html` в браузере. Интернет не нужен.

## Управление (простое!)

| Клавиша | Действие |
|---|---|
| `A` `D` / стрелки | идти |
| `W` | прыжок (в воздухе — **второй прыжок**) |
| `ПРОБЕЛ` | удар (см. комбо ниже) |
| `U` | **сверхудар**, когда готова Ярость |
| `ESC` | пауза |

## Четыре вида комбо

Одна кнопка боя, но удары **зависят от ситуации**:

| Как нажать | Что будет |
|---|---|
| **ПРОБЕЛ на месте** | серия из трёх ударов, **третий подбрасывает врага в воздух** |
| **ПРОБЕЛ + в сторону врага** | длинный **выпад** — достаёт с дистанции, сбивает |
| **ПРОБЕЛ + от врага** | **отступающий удар** — бьёте на отходе |
| **ПРОБЕЛ в воздухе** | **обрушение сверху** — вбивает врага в пол |

### Жонглирование
Подброшенного врага можно добивать в воздухе, не давая упасть — урон растёт,
а серия не сбрасывается. За **3, 5, 8, 12 и 18** ударов подряд Мурзик получает
титул («Хорошо!», «Отлично!», «Великолепно!», «НЕВЕРОЯТНО!», «ЛЕГЕНДА!»), экран
вспыхивает цветом ранга, и играется особый звук. Серия держится 0.42 секунды.

## Противники

| Противник | Характер |
|---|---|
| **Барсик** | дерётся честно и просто |
| **Васька** | наглый и очень быстрый, давит напором |
| **Борис** | огромный запас здоровья, медленный, но **таранит** с разбега |
| **Сфинкс** | **уклоняется** от ваших ударов и прыгает |
| **Ночная Тень** | **исчезает и появляется за спиной** |
| **Подушечный Король** | босс, ярость копится очень быстро |

За победу вы выбираете **новую подушку** и **усиление**. Проиграли — теряете ♥,
но противник остаётся тот же, можно взять реванш. Всего **4 жизни**.

## Подушки (7 видов — у каждой свой размер, форма и СВОЯ супер-атака)

| Подушка | Форма | Эффект удара | Супер-атака (U) |
|---|---|---|---|
| 🧸 Классическая | обычная | ровный урон | **ВИХРЬ ПУХА** — круговой удар по всему вокруг |
| 🪶 Пуховая | длинная | на 34% быстрее, слабее | **ШКВАЛ ПУХА** — три мгновенных удара издалека |
| 🪨 Каменная | большая | сильный удар, дальний отброс | **ЗЕМЛЕТРЯСЕНИЕ** — прыжок и удар по полу, подбрасывает |
| ⚡ Электро | круглая | удлиняет оглушение | **ЦЕПНАЯ МОЛНИЯ** — разряд, надолго оглушает |
| 🔥 Огненная | круглая | поджигает | **ОГНЕННЫЙ ВАЛ** — волна пламени, горит 6 секунд |
| ❄ Ледяная | круглая | замедляет | **ЛЕДЯНАЯ ГЛЫБА** — сковывает врага полностью |
| 🌈 Радужная | маленькая | ярость ×1.45 | **РАДУЖНЫЙ ЛУЧ** — пробивает через всю арену |

Подушки отличаются **видом в лапе**: длинная колбаска, большой квадрат, круглая
или маленькая. Название супер-атаки видно в HUD, когда шкала Ярости полна.
Между боями подушку **можно переключить** на любую открытую.

## Арены (6 разных комнат)

У каждого противника своя комната со своим декором:

| Арена | Что внутри |
|---|---|
| **Гостиная** | окно с луной, диван, торшер, растение, картины |
| **Кухня** | полки с банками, плита с конфорками, стол, дневное окно |
| **Чердак** | деревянные балки, ящики, старая лампа, паутина |
| **Ванная** | кафель, зеркало, раковина, полка |
| **Ночная комната** | звёзды, лунный свет, тёмная мебель |
| **Тронный зал** | колонны, факелы, трон, знамя |

## Усиления (12 видов)

Здоровье, урон, скорость, накопление ярости, прыжок, сила сверхудара,
регенерация, скорость комбо, дальность ударов, **когти вампира** (каждый третий
удар лечит), **пуховый щит** (поглощает один удар за бой) и **кошачья удача**.

## Анимации ударов и эффекты

- Замах с наклоном корпуса назад, рывок вперёд и возврат.
- **Дуга взмаха** со светящейся кромкой и **искры** в цвет эффекта подушки.
- **Звезда-вспышка** в точке попадания и **ударная волна** от сверхудара.
- **Толчок камеры** (короткий зум) на сильных ударах и **замедление времени** при нокауте.
- **Пыль** от прыжков и жёстких приземлений, **линии скорости** при рывках.
- Ореолы горения и заморозки, перья, пух, цифры урона, тряска экрана.
- Счётчик комбо с ранговой полоской прямо в HUD.

## Детали реализации

- Вся графика рисуется кодом на `<canvas>`: коты из эллипсов и градиентов,
  комнатный фон с окном, луной, диваном, торшером и растением.
- Поддержка Retina — картинка резкая на любом экране.
- Звуки синтезируются через Web Audio — внешних файлов нет.

## Как поменять настройки

- Противники — массив `OPPONENTS` (здоровье, скорость, характер, цвет).
- Подушки — массив `PILLOWS`, усиления — `BONUSES`.
- Серия ударов — `COMBO`, удар в воздухе — `AIR_ATK`, сверхудар — `SUPER`.
- Количество жизней — константа `LIVES`.

# МЕЧ И НЕЧИСТЬ — 2D пиксельная action-RPG


Бегайте с мечом по деревне, лесу, кладбищу и пещере, рубите зомби, гоблинов,
вампиров и чертиков, ищите сокровища в домах и качайте героя, чтобы одолеть
Владыку Нечисти.

**Играть:** откройте `sword-2d.html` в браузере. Интернет не нужен.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` или стрелки | идти |
| `ПРОБЕЛ` | удар мечом |
| `SHIFT` | рывок |
| `L` | вихрь (круговой удар, после покупки) |
| `E` | войти в дом, открыть сундук, поговорить |
| `ESC` | пауза |

На телефоне появляются кнопки на экране.

## Как играть

**Цель:** найти **3 кристалла** в сундуках (лес, кладбище, пещера), затем вернуться
в деревню, войти в портал и победить **Владыку Нечисти**.

**Локации:** деревня, тёмный лес, кладбище, пещера и логово. Между ними — переходы
по краям карты. На каждой локации есть **домики, в которые можно зайти**: дом,
лавка, лагерь, хижина, склеп и заброшенная шахта. Внутри — сундуки, горшки и NPC.

**Враги:**

| Враг | Особенность |
|---|---|
| 🟢 Зомби | медленный, но живучий |
| 🟠 Гоблин | быстрый, кидает камни и держит дистанцию |
| ⚪ Вампир | делает резкие рывки |
| 🔴 Чёртик | стреляет огнём |
| 🟣 Владыка | босс в логове, много здоровья |

**Сокровища и усиления:** в сундуках — золото, кристаллы и усиления (лечение, сила,
сапоги, щит, ярость). Разбивайте горшки — оттуда тоже выпадает золото.

**Прокачка в лавке:** мечи (5 уровней — от Ржавого меча до Клинка Света), броня
(5 уровней, снижает урон), здоровье (+8 за уровень), рывок, вихрь и попутчики.

**Попутчики:** волк бросается на врагов, фея лечит вас, лучник стреляет из лука.
Каждого можно улучшить до 2 уровня.

**Опыт:** за убийства растёт уровень — герой становится крепче. Прогресс
сохраняется автоматически в браузере, можно продолжить позже.

## Детали реализации

- Вся графика рисуется кодом на `<canvas>` 480×270 с пиксельным масштабированием.
- Карты 40×24 плитки, камера следует за героем. Все локации описаны понятными
  функциями и генерируются с фиксированным зерном — карта всегда одна и та же.
- Враги собираются процедурно, у NPC и домов своя анимация и двери.
- Функция `fixArrivals` следит, чтобы точка старта, спавна и прибытия всегда была
  на свободной клетке — игрок не может застрять в стене.
- Звуки синтезируются через Web Audio. Внешних файлов нет.

## Как поменять настройки

Враги и их параметры — в объекте `ENEMY_DEF`, оружие — в `WEAPONS`, броня — в
`ARMORS`, способности и цены — `DASH_COST` / `WHIRL_COST`, попутчики — в
`COMPANIONS`. Локации строятся в функции `buildWorld`.

# ТУАЛЕТ ЗА РУБЛЬ — 2D пиксельная игра


Вы — единственный сотрудник платного туалета. Пропускайте посетителей за рубль,
распознавайте и выгоняйте жуликов, убирайте мусор, прочищайте унитазы и
улучшайте туалет между сменами. Продержитесь 4 смены!

**Играть:** откройте `toilet-2d.html` в браузере. Всё уже готово — интернет не нужен.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` или стрелки | ходить |
| `E` | пропустить гостя · выставить жулика · **держать** — убрать/прочистить |
| `R` | прогнать посетителя |
| `Q` | проверить подозрительного (займёт ~1 секунду) |
| `ESC` | пауза |

На телефоне появляются кнопки управления на экране.

## Как играть

У входа стоит посетитель. Над ним виден **рубль** — это оплата. Решайте:

- **Обычный человек** — есть рубль, иногда сумка или телефон. Пропустите его (`E`),
  получите 1 ₽.
- **Жулик** — выдаёт себя признаком: **маска**, **лом** или **баллончик**.
  Прогоните его (`R`) и получите очко серии.
- Сомневаетесь — нажмите **`Q`** и подождите: над головой появится **ЖУЛИК**
  или **ЧИСТЫЙ**. Но проверка отнимает время, а очередь ждёт.

Внутри туалета:

- Если жулик всё же пролез — он ворует деньги, сорит, засоряет унитазы и рисует
  мазню. **Подбегите к нему и нажмите `E`**, чтобы выставить.
- **Держите `E`** у пятна, лужи, мусора — прогресс-полоска покажет уборку.
- **Держите `E`** у засорённого унитаза — прочистите его. Красный флаг появляется
  над засором.
- Слишком много грязи — **полоска «Чистота»** падает. Упадёт до нуля — потеряете ♥.

Между сменами открывается **магазин улучшений**, а в кассе видно заработок.
Каждое улучшение реально видно в туалете: кафель, зеркало, замочки, освежитель,
камера. 3 сердца. 4 смены: 6, 8, 10 и 12 гостей, жуликов всё больше.

## Детали реализации

- Вся графика рисуется кодом на `<canvas>` 480×270 и растягивается с пиксельным
  масштабированием.
- Посетители собираются процедурно: цвет кожи, одежды, волос, шляпа и набор
  признаков-иконок.
- Грязь появляется на свободных точках пола, а не внутри мебели.
- Звуки синтезируются через Web Audio — внешних файлов нет.
- Есть пауза, магазин между сменами, экраны победы и поражения.

## Как поменять настройки

Сложность каждой смены — в функции `shiftCfg`:

```js
function shiftCfg(s){
  return {
    normals:    [0,6,8,10,12][s],       // сколько честных гостей
    hooligans:  [0,3,5,7,9][s],         // сколько жуликов
    patience:   Math.max(8, 14-s),      // сколько ждут (секунды)
    dirtEvery:  Math.max(2.2, 5.0-s*0.8), // как часто появляется грязь
    ...
  };
}
```

Цены и эффекты улучшений — в массиве `UPGRADES`, признаки жуликов — в `TRAITS`,
виды грязи — в `DIRT_DEF`. Количество смен — в константе `TOTAL_SHIFTS`.

# БУРГЕРНАЯ У ЗВЕРЕЙ — 2D пиксельная игра


Кулинарная аркада: жарьте котлеты, режьте овощи, собирайте бургеры и обслуживайте
очередь клиентов-животных. Продержитесь 4 смены!

**Играть:** откройте `burger-2d.html` в браузере. Всё уже готово — интернет не нужен.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` или стрелки | ходить по кухне |
| `E` или `ПРОБЕЛ` | действие у станции / снять котлету / рубить / подать заказ |
| `1`…`6` | быстро положить ингредиент в сборке |
| `ESC` | пауза / выйти из мини-игры |

На телефоне появляются кнопки управления на экране.

## Как играть

1. **Гриль** — жарьте котлету и снимите её, пока метка в зелёной зоне.
   Рано снимете — сырая, поздно — сгорит.
2. **Нарезка** — рубите ножом, пока белая метка в зелёной зоне. Нужно попасть
   несколько раз подряд.
3. **Сборка** — соберите бургер в порядке заказа. Жёлтая рамка подсказывает,
   какие ингредиенты есть в заказе.
4. **Окно выдачи** — отдайте бургер переднему клиенту.
5. **Мусорка** — выбросить неудачные бургеры.

- У каждого клиента своя полоска терпения. Уйдёт — потеряете ♥.
- Соблюдайте порядок сборки: за ошибку клиент нервничает.
- За быструю подачу — чаевые. Подряд без ошибок растёт «серия» и множитель денег.
- 3 сердца. 4 смены с растущей сложностью: больше клиентов, короче терпение,
  быстрее готовка, больше ингредиентов.
- Между сменами выбирайте улучшение: скорость, мастерство гриля и нарезки,
  терпение клиентов, чаевые, ловкость рук.

## Детали реализации

- Вся графика рисуется кодом на `<canvas>` 480×270 и растягивается с пиксельным
  масштабированием — картинка остаётся «пиксельной».
- 10 видов клиентов-животных (кот, пёс, заяц, медведь, лиса, панда, свин, жаба,
  корова, сова) рисуются кодом: форма ушей, морда, мигание, покачивание.
- Иконки ингредиентов собираются в спрайт-атлас через `canvas.toDataURL()`.
- Звуки синтезируются через Web Audio — никаких внешних файлов.
- Есть пауза, панель улучшений между сменами, экраны победы и поражения.

## Как поменять настройки

Откройте `burger-2d.html` в блокноте и найдите функцию `shiftCfg` — там сложность
каждой смены:

```js
function shiftCfg(s){
  return {
    customers:  [0,4,6,8,10][s],        // сколько клиентов за смену
    patience:   Math.max(16, 32-s*3),   // сколько терпят (секунды)
    spawnEvery: Math.max(6, 14-s*2),    // как часто приходят
    grillSpeed: 0.30+0.05*s,            // скорость метки на гриле
    grillZoneW: Math.max(0.17,0.36-0.03*s), // ширина зелёной зоны
    ...
  };
}
```

Ингредиенты и их цены — в объекте `ING`, улучшения — в массиве `UPGRADES`,
количество смен — в константе `TOTAL_SHIFTS`.

# ПРЫГО·ПАРКУР — пиксельный платформер

Браузерная игра в стиле классических платформеров: бегаем, прыгаем, топчем врагов
и взбираемся по стенам, чтобы добраться до флага.

**Играть:** откройте `index.html` в браузере. Всё уже готово — интернет не нужен.


## Что ещё лежит в проекте

| Файл | Что это |
|---|---|
| `toilet-2d.html` | **Туалет за рубль** — 2D пиксельная игра про платный туалет |
| `burger-2d.html` | **Бургерная у зверей** — 2D пиксельная кулинарная аркада |
| `shooter-3d.html` | 3D-шутер от первого лица с монстрами (нужен `three.min.js`) |
| `tir-2d.html` | Первая версия — 2D-тир по мишеням |

## Управление

| Клавиша | Действие |
|---|---|
| `A` / `D` или `←` / `→` | бежать |
| `ПРОБЕЛ` | прыжок (чем дольше держите, тем выше) |
| `ПРОБЕЛ` у стены | прыжок от стены |
| `SHIFT` | ускорение |
| `ESC` | пауза |

На телефоне появляются кнопки управления на экране.

## Правила

- **Гумба** (коричневый) — топчите сверху, получаете очки.
- **Колючка** (фиолетовый, с шипами) — топтать **нельзя**, только обходить.
- **Летун** (оранжевый, с крыльями) — летает и преследует вас.
- **Шипы** и падения в пропасть — смертельны.
- **`?`-блоки** дают монеты, если ударить по ним головой снизу.
- **Движущиеся платформы** перевозят вас через пропасти.
- 3 жизни. Собрали монеты, дошли до флага — уровень пройден.
- За остаток времени в конце уровня начисляются бонусные очки.

## Детали реализации

- Вся графика рисуется кодом на `<canvas>` в разрешении 416×224 и растягивается
  с пиксельным масштабированием — поэтому картинка остаётся «пиксельной».
- Спрайты персонажей описаны как символьные карты и раскрашиваются палитрой.
- Звуки синтезируются через Web Audio — никаких внешних файлов.
- Физика с фиксированным шагом: «coyote time», буфер прыжка, переменная высота
  прыжка, скольжение и отталкивание от стен.
- Рекорд не сохраняется — игра рассчитана на прохождение подряд.

## Как поменять настройки

Откройте `index.html` в блокноте и найдите блок `CFG` — там гравитация, скорость
бега, сила прыжка и прочее:

```js
const CFG = {
  gravity:    1500,   // гравитация
  maxWalk:     112,   // скорость обычной ходьбы
  maxRun:      196,   // скорость с SHIFT
  jumpVel:    -420,   // сила прыжка
  ...
};
```

Уровень описан в функции `buildLevel` понятными командами:

```js
ground(0, 27, 11);        // земля с 0 по 27 плитку, поверхность на 11 строке
pipe(36, 2, 11);          // труба
coinRow(9, 11, 5);        // ряд монет
rect(96, 4, 96, 8, '#');  // блок из левого-верхнего в правый-нижний угол
```
