со ссылками на все игры.

## Про игру «Бой на подушках»

2D файтинг с видом сбоку. Управление:

- `A` `D` — идти
- `W` — прыжок (в воздухе второй раз)
- `ПРОБЕЛ` — удар (комбо / выпад / отступ / воздух)
- `U` — супер-атака подушки (когда полна шкала Ярости)
- `ESC` — пауза

7 подушек со своими супер-атаками, 6 арен, 12 усилений, 6 противников.

## Технические заметки

- Все игры — отдельные HTML-файлы, графика рисуется кодом.
- `dead-horizon.html` и `shooter-3d.html` используют `three.min.js` (лежит рядом).
- Звук синтезируется через Web Audio, внешних аудиофайлов нет.

## Как добавить игру

1. Положите файл в корень репозитория.
2. Добавьте запись в массив `GAMES` в `index.html`.
